# 00 Start note

> [!success] AI agents read first
> This is the ==entry note== for Stanley website v2. Start here, then move into the lifecycle notes below.

## Project goal
- Build a new personal website (V2) with AI agents.
- Launch a clean portfolio website on Vercel.
- Learn product building, design, implementation, testing, deployment, and operation through the project.

## Product intent
- Portfolio first
- Learning project second
- Future reusable process later

## Working rules
- Keep V1 small and realistic.
- Prefer simple, inspectable systems.
- Use free or low-cost tools first.
- Document decisions in the lifecycle notes instead of spreading them across many side notes.
- Do not put any content on the website unless it already appears in [[03 Product spec]].
- If a page, section, CTA, link, or copy is missing from [[03 Product spec]], update the spec first instead of inventing website content.
- Before doing a job, every agent must check the related notes in `20260313 Stanley Website`.
- After an agent finishes a job, it must review and update the related lifecycle note before the task is considered done.
- If a note with a similar function already exists, update or merge it instead of creating a new note.
- In project-folder notes, agents do not need to change the `organized` property after normal edits.
